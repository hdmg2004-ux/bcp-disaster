# 発災時行動判断支援ツール

東京医療減災Labo（東京都立病院機構）が無償提供する、
病院の発災時行動判断を支援するHTMLツールです。

院内の設備・部門の状況を ○△× で評価すると、被害程度と、外来・入院の行動基準が分かります。
評価の帳票は『行動判断支援票2026』と同じ構造で、A4 に印刷して掲示できます。

## 使い方は2通り

### Web版（ブラウザで開くだけ）

👉 https://bcp-disaster.vercel.app/

- 一度開けば、その端末ではオフラインでも動きます
- 新しい版が公開されると、画面の下でお知らせします。「更新する」を押したときだけ切り替わります
- 入力した内容はその端末に保存されます。更新しても消えません

### ファイル版（ダウンロードして使う）

1. 👉 [最新版をダウンロード](https://github.com/hdmg2004-ux/bcp-disaster/releases/latest)（Assets の `bcp_disaster.html`）
2. ダウンロードしたファイルをブラウザで開く
3. 「初回設定」タブで病院名・診療科をチェックして保存

ネット接続は不要です。防災センターのPCや当直室の端末など、発災時に手に取れる場所に保存しておいてください。

印刷レイアウトは Google Chrome を基準に調整しています。

## 設計思想

EMIS等の外部システムとの連携はあえて行いません。
完全に独立した、シンプルで確実に動くツールを目指しています。
利便性の追求は、災害時には障害の原因になります。
シンプル・イズ・ベスト。
