# 発災時行動判断支援ツール

東京医療減災Labo（東京都立病院機構）が無償提供する、
病院の発災時行動判断を支援するHTMLツールです。

## v2.0での変更点

地震専用版から、**地震・水害・降灰に対応するオールハザード版**へ拡張しました。災害種別ごとに個別のツールを作るのではなく、共通の骨格（フェーズ・組織構造・評価エンジン）に種別ごとのパラメータを差し込む設計です。

## 推奨ブラウザ

評価画面（Step1〜3）の項目欄には縦書きのカテゴリラベル（インフラ系・医療ガス系等）を含みます。印刷レイアウトは **Google Chrome** での動作を基準に調整しています。Safari・DuckDuckGoブラウザ等では、印刷結果のレイアウトが崩れる場合があります。

画面上での評価・閲覧はどのブラウザでも支障ありません。印刷して掲示する際は、可能な限りChromeを使用してください。平時の準備段階で、実際に使用する端末・ブラウザで一度試し印刷を行い、レイアウトを確認しておくことを推奨します。

## 使い方

1. 下の **Releases** からツールをダウンロード
2. ダウンロードした `bcp_disaster.html` をブラウザで開く
3. 「初回設定」タブで病院名・診療科チェックを入力して保存

ネット接続不要。設定はブラウザのローカルストレージに保存されます。

## 設計思想

EMIS等の外部システムとの連携はあえて行いません。
完全に独立した、シンプルで確実に動くツールを目指しています。
利便性の追求は、災害時には障害の原因になります。
シンプル・イズ・ベスト。

災害種別ごとに別のツールを作ることもしません。地震・水害・降灰は骨格を共有し、違いはパラメータの差としてのみ表現します。「種別ごとに個別のBCPを作り込む」という既存の考え方へのアンチテーゼです。
